# diseños_base — Mockups HTML de referencia

Sube aquí los HTML/CSS de UI aprobados (login, dashboard, personal, carga, asistencia, justificaciones, reportes).

## Convención

- Archivos estáticos de referencia para el equipo y para Codex (`frontend_react`).
- No son la app React final; sirven de guía visual y de flujo (wizard, panel 90/10, etc.).
- Nombres sugeridos:
  - `login.html`
  - `dashboard.html`
  - `personal.html`
  - `carga.html`
  - `asistencia.html`
  - `justificaciones.html`
  - `reportes.html`
  - `styles.css`
  - `index.html` (índice de pantallas)

El frontend real vive en `frontend/` y debe respetar estos flujos (skill UI + wizard).
